## サーバーチャンネル、ロール、アナウンスの歩き方

サーバーに参加した直後は、近代的な Discord コミュニティの構成に慣れていないと、カテゴリの多さに圧倒されてしまうかもしれません。しかし、通知ロールの設定に5分ほど時間をかけるだけで、関係のない雑談の通知に煩わされることなく、重要なアップデート情報だけを確実に受け取れるようになります。

├── 💬 General Lounges（雑談、ペット自慢、メディア共有）

## コミュニティのエチケット、トレードのガイドライン、安全対策

大規模なゲームコミュニティには悪意ある人物が紛れ込む可能性があるため、自身のアカウントやゲーム内資産を守ることが何よりも重要です。当コミュニティでは、詐欺、なりすまし、不正なリアルマネートレード（RMT）を防止するための厳格な取引ルールを設けています。

送信者がサーバー管理者やBotを名乗っている場合であっても、ダイレクトメッセージ（DM）で送られてきた不審なリンクは絶対にクリックしないでください。正規のモデレーターがアカウントのパスワード、メール認証コード、二要素認証トークンを尋ねることは決してありません。アカウントのプライバシーと安全を常に最高レベルに保つため、公式の [Discord Safety Guidelines](https://discord.com/safety) に必ず従ってください。

### 推奨されるトレード安全チェックリスト

1. **ゲーム内ユーザー名の照合**: Discord のユーザー名と、サーバー内の信用ログ（vouch log）に記載されているゲーム内のキャラクター名が一致しているかクロスチェックする。
2. **プラットフォーム外でのやり取りを拒否**: 外部サイト、サードパーティ製メッセージアプリ、送金サービス等での取引完了を要求された場合は即座に断る。
3. **ピン留めされた相場表の活用**: コミュニティが作成した最新の価格チャートを確認し、著しく不当な取引や買い叩き・搾取を避ける。
4. **全トレードの証拠を残す**: 画面を録画するか、取引の合意内容およびゲーム内の最終確認画面のスクリーンショットを明確に撮影しておく。

| トレードにおける行動 | 安全な手順 | 危険な行動／警戒すべき兆候 |
| :--- | :--- | :--- |
| **取引の募集・開始** | `#companion-trading` に公開投稿する | 「都合が良すぎる」好条件の取引を持ちかける突然のDM |
| **トレードの実行** | ゲームの公式クライアント内で直接同時交換を行う | オープンマップ上にアイテムをドロップさせるなどの複数段階の取引 |
| **相手の信用確認** | ハブ内の過去の取引実績スレッド（vouch）を確認する | 取引履歴が全くない新規作成の Discord アカウントを信用する |
| **対価の支払い** | ゲーム内通貨およびコンパニオンの相互トレード | ギフトカード、暗号資産、送金アプリでの支払いを要求される |
| **トラブルの解決** | サーバーのサポートBotからチケットを発行して通報 | 公共チャンネルで相手を晒し上げたり、報復詐欺を試みたりする |

## イベント、プレゼント企画、コミュニティコンテストへの参加

プレイヤーの体験談からも、コミュニティコンテストは参加者数に対する賞品枠が手厚いことが多く、課金することなく貴重なアイテムを入手できる素晴らしい手段であることが分かっています。イベントは主に、コミュニティアートコンテスト、ゲーム内チャレンジ、クイズナイトの3つの形式に分かれています。

| イベント形式 | 開催頻度 | 参加要件 | 主な報酬内容 |

プレゼント企画に参加する際は、お使いの Discord アカウントで電話番号またはメールアドレスの認証が完了していることを確認してください。自動セキュリティBotが定期的に応募アカウントを巡回し、複数作成された複垢Botを自動除外することで、本物のコミュニティメンバーに賞品が行き渡るよう管理されています。

## Discord へのアクセスおよび認証トラブルの解決方法

**wonderpaws discord** に参加しようとした際や、サーバー内での認証を進める際に問題が発生することが時折あります。大型パッチの配信直後などサーバーへのアクセスが急増する時間帯には、荒らし対策（Anti-Raid）の自動シールドが作動し、一時的に新規参加の手続きが遅延する場合があります。

認証のループから抜け出せなくなったり、招待を承諾したのにチャンネルが表示されない場合は、以下のトラブルシューティング手順に沿って対応することで、数分以内に問題を解決できます。

| トラブル内容 | 考えられる原因 | 段階的な解決手順 |
| :--- | :--- | :--- |
| **招待リンクが無効または期限切れ** | 古いカスタムURL、またはサーバー人数が上限に達している | 開発元の公式サイトまたは Steam コミュニティハブから最新の公式リンクを取得する。 |
| **チャットチャンネルが表示されない** | オンボーディング未完了、または利用規約に未同意 | `#rules-and-info` の一番下までスクロールし、緑のチェックマーク（チェックのリアクション）を押す。 |
| **Botの認証タイムアウト** | DMのプライバシー設定が厳格でCaptcha Botからメッセージが届かない | プライバシー設定で「サーバーメンバーからのDM」を一時的に許可し、再度認証を試す。 |
| **参加直後に即キックされる** | IPのブラックリスト検知、電話認証未完了、またはVPN使用 | 接続中のVPNを無効化し、Discord プロフィールに有効な携帯電話番号を連携する。 |
| **読み取り専用になって書き込めない** | 荒らし対策のためサーバー全体が一時ロックされている | 公式の稼働ステータスを確認し、自動ロックダウンが解除されるまで15〜30分待機する。 |

どうしても自力で解決できない場合は、専用のサポートチケットBotを通じてコミュニティのモデレーターやヘルパースタッフへ問い合わせることで、自動認証の不具合を安全に解除してもらえます。

## Wonderpaws Discord に関するよくある質問（FAQ）

### Wonderpaws Discord の正規の招待リンクはどこで確認できますか？
最も安全な参加方法は、ゲームのランチャー、公式サイトのフッター、または認証済みの Steam コミュニティページなど、公式の情報源からアクセスすることです。サードパーティの掲示板リンクや検索エンジンの広告は、アカウント情報を盗み取る目的で作られた非公式のフィッシングサーバーへ誘導される恐れがあるためクリックしないでください。

### パーティ募集に参加する場合、ボイスチャットは必須ですか？
いいえ、ボイスチャットへの参加は完全に任意です。最高難度のダンジョン攻略などでは連携のためにボイスチャンネルが用意されていますが、コミュニティには活発なテキスト募集チャンネル（`#lfg-text`）も常設されており、ゲーム内のピン機能や気軽なテキストチャットだけで円滑にプレイ可能です。

### サーバー内で詐欺に遭いそうになった場合はどうすればよいですか？
やり取りの明確なスクリーンショットを撮影し、該当ユーザー固有の Discord Snowflake ID（ユーザーを右クリック ＞「ユーザーIDをコピー」）を控えた上で、サーバーのサポートBotから通報チケットを作成してください。サーバーの規約違反となるため、公共のチャンネルで晒し上げたり、私刑を行ったりすることは絶対にやめてください。

### チャンネル内で自分の Wonderpaws の配信や YouTube 攻略動画を宣伝してもいいですか？
多くのコミュニティハブには、専用の `#community-creations` または `#content-creators` チャンネルが用意されています。自己宣伝に関する独自の利用規約を事前に必ず確認してください。一般的に `#general-chat` や `#builds-and-tips` などの通常チャンネルで個人のコンテンツを宣伝する行為は禁止されています。
